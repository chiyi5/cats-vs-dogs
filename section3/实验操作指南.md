## 2. e) 错误分析

```bash
python section3/error_analysis.py \
    --predictions section2/results/MF_seed42/val_predictions.csv \
    --data data/datasets --output section3/artifacts
```

- 默认挑 4 个错误 + 2 个正确，按置信度从高到低
- 生成 `error_cases.csv` 与 `error_examples.png`
- **必须手工打开 `error_cases.csv`，给每个样例填 `error_type`**，例如：
  - `background` 背景误导（沙发/草地让模型联想到另一类）
  - `partial` 主体只露出一部分
  - `low_resolution` 图像太小、模糊
  - `similar_texture` 毛色或纹理接近
  - `multi_object` 多主体干扰

报告中要写明：**test 集没有标签，因此错误分析在验证集上进行**。

## 3. g) CIFAR-10

```bash
python section3/cifar.py --experiment C1 --seed 42 --data data/cifar10 --amp
```

设置：

- ResNet18 从零训练，10 类输出，输入 32×32
- 增强：RandomCrop(32, padding=4) + 水平翻转
- SGD，学习率 0.1，momentum 0.9，weight decay 5e-4，余弦调度
- 30 轮，batch size 128
- 官方训练集划出 45000 训练 / 5000 验证，**测试集 10000 张只在最后评估一次**

报告中 g) 要说明相对猫狗任务改了什么：

| 项 | 猫狗 | CIFAR-10 |
|---|---|---|
| 输入 | 224×224 | 32×32 |
| 类别数 | 2 | 10 |
| 权重 | ImageNet 预训练 | 从零训练 |
| 增强 | 翻转 + 旋转 | 裁剪 + 翻转（32×32 上旋转会破坏图像） |
| 难点 | 类间相似、背景干扰 | 四足动物互相混淆（cat/dog/deer/horse） |

## 4. h) 类别不平衡

```bash
python section3/run_all.py --queue H0:42 H1:42 H2:42 --data data/cifar10 --amp
```

构造方式（已固定在代码中，需写进报告）：

- 类别 0–4 为少数类，每类只保留 10%
- 类别 5–9 保留全部
- 抽样种子 42，保留索引记录在 `config.json` 的 `imbalance` 字段
- 验证集与测试集**保持平衡**，否则无法看出少数类是否真的改善

三种方法：

| 编号 | 做法 | 实现 |
|---|---|---|
| H0 | 不做处理 | 普通交叉熵（对照组） |
| H1 | 过采样少数类 | `WeightedRandomSampler`，权重与类别频数成反比 |
| H2 | 类别加权损失 | `CrossEntropyLoss(weight=...)`，权重与类别频数成反比 |

报告 h) 的要求：

- 不能只报总体准确率，必须给**每类召回 + macro-F1 + 混淆矩阵**
- 说明代价：多数类召回是否下降、总体准确率是否被牺牲
- 解释为什么总体准确率会掩盖问题（多数类占样本量绝大多数）
