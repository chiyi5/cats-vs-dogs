# 包②：主模型包操作指南

对应 `plan.md` 第 5 节，负责报告中的数据、b)、c)、d) 四节和 `submission.csv`。

## 1. 与 section1 的协议对齐

`M0` 是 section1 `E1` 的复刻，二者唯一允许的差异是：**运行机器不同**。因此：

- 相同的模型：ResNet18 + ImageNet1K_V1 权重，换 2 类输出
- 相同的数据：`section1/artifacts/excluded_train.json` 排除 6 张后的 19994 张
- 相同的预处理：短边 resize 到 256、中心裁剪 224、ImageNet 归一化
- 相同的增强：水平翻转 + ±10° 旋转
- 相同的优化：SGD，momentum 0.9，weight decay 1e-4，初始学习率 1e-3，余弦调度
- 相同的训练预算：20 轮、batch size 16、混合精度

`M0` 的验证准确率与 `E1`（99.16%）相差超过 0.5 个百分点时，说明预处理或排除清单不一致，必须先排查，不能继续。

## 2. 运行顺序

```bash
python section2/prepare_data.py --data data/datasets
python section2/train.py --data data/datasets --experiment M0 --seed 42 \
    --output section2/results --amp
```

`M0` 通过后：

```bash
python section2/run_all.py --data data/datasets --amp
```

`run_all.py` 按 `M0→M1→M2→M3→M4→MF(42/123/2026)` 顺序执行，已有 `metrics.json` 的运行会自动跳过，队列状态写入 `artifacts/queue_status.json`。中途失败会立即停止，不会继续消耗时间。

集群上提交作业：

```bash
#!/bin/bash
#SBATCH --job-name=s2
#SBATCH --partition=<GPU 分区>
#SBATCH --gres=gpu:1
#SBATCH --cpus-per-task=4
#SBATCH --mem=16G
#SBATCH --time=04:00:00
#SBATCH --output=log/s2-%j.out

cd ~/6483
python section2/run_all.py --data data/datasets --amp
```

注意：不要在 login 节点跑训练，最后一个 SSH 会话断开时进程会被杀掉。

## 3. 实验解释

| 编号 | 与 M0 的差别 | 回答什么问题 |
|---|---|---|
| M1 | 学习率改为 1e-4 | 学习率是否太小 |
| M2 | 学习率改为 1e-2 | 学习率是否过大、是否发散 |
| M3 | 冻结主干，只训练分类层 | 全量微调是否必要、成本差多少 |
| M4 | 30 轮 | 20 轮是否已收敛 |

写 c) 时按实测差值说明，例如「学习率从 1e-3 降到 1e-4，验证准确率下降 x 个百分点」，不写「经验上」。

若 M1、M2 都不如 M0，据实报告，这本身就是一个有价值的结论。

## 4. 最终模型与提交

`MF` 使用 M0–M4 中验证最优的配置。如果最优配置不是 M0（学习率 1e-3、20 轮），直接传参覆盖：

```bash
python section2/train.py --data data/datasets --experiment MF --seed 42 \
    --output section2/results --amp --lr 0.0001 --epochs 30
```

三个种子跑完后，用验证准确率最高的种子生成提交文件：

```bash
python section2/predict.py --run section2/results/MF_seed42 \
    --data data/datasets --output section2/artifacts/submission.csv
```

提交前检查：

- 严格 500 行（不含表头）
- id 为 1–500 且连续
- label 只有 0 和 1

脚本会自动校验，不满足会打印 WARNING。

## 5. 汇总与报告

```bash
python section2/summarize_results.py
```

输出 `results.csv`（逐次运行）、`results_summary.csv`（均值 ± 标准差）、`validation_accuracy.png`、`learning_curves.png`。

写 b) 时还需要补一张模型架构图。可以用：

```bash
python -c "from torchvision import models; import torchinfo; \
print(torchinfo.summary(models.resnet18(num_classes=2), input_size=(1,3,224,224)))"
```

没有 `torchinfo` 时用 `torchsummary`，或直接截图画出模块块图。

## 6. 与 section3 的交接

section3 需要以下文件：

| 文件 | 说明 |
|---|---|
| `section2/results/MF_seed<最优>/best.pt` | 最终权重（不进 Git） |
| 同目录 `config.json` | 尺寸、类别映射、协议 |
| 同目录 `val_predictions.csv` | 5000 行验证预测（带 prob_dog） |
| `section2/artifacts/submission.csv` | 提交文件 |

因为 `*.pt` 被 `.gitignore` 排除，权重需要 scp 或经集群共享目录传递。
